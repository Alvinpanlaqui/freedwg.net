AutoCAD Keyboard Shortcuts & Function Reference

Enhance your CAD productivity with essential command shortcuts, control key modifiers, and function key toggles.

Drawing Commands

  • LLine
    Creates straight line segments
  • PLPolyline
    Creates a connected 2D polyline
  • CCircle
    Draws a circle using center & radius
  • RECRectangle
    Draws a rectangular polyline
  • AArc
    Creates a curved arc segment
  • HHatch
    Fills an enclosed area with pattern

Modification Commands

  • CO / CPCopy
    Duplicates objects at a specified distance
  • MMove
    Relocates objects without changing size
  • RORotate
    Turns objects around a base point
  • TRTrim
    Cuts objects to meet other edges
  • EXExtend
    Lengthens objects to meet boundaries
  • OOffset
    Creates parallel concentric copies

Control Key Shortcuts (Ctrl)

  • Ctrl + SSave
    Saves current drawing file
  • Ctrl + ZUndo
    Reverses the last action taken
  • Ctrl + YRedo
    Restores previously undone action
  • Ctrl + CCopy
    Copies selected objects to clipboard
  • Ctrl + VPaste
    Pastes objects from clipboard
  • Ctrl + 1Properties
    Opens Object Properties palette

Function Key Toggles (F1–F12)

  • F1Help
    Opens AutoCAD Help window
  • F3OSNAP
    Toggles Running Object Snaps
  • F7Grid
    Toggles drawing grid display
  • F8Ortho
    Locks cursor to horizontal/vertical
  • F9Snap
    Toggles snap increments
  • F10Polar
    Toggles polar tracking angles
